## Pull (ItemId=2)
Semantics:
- TargetCell = empty destination (ValidateTarget: Empty, in bounds)
- Orthogonally adjacent (N/E/S/W) find a stone to pull: occupied, not Blocked, not GuardianProtected
- Prefer opponent stone (owner != PlayerId); else fail if only own stone (or allow any stone — prefer opponent-only)
- If no valid adjacent stone → ValidateTarget false AND Execute false
- Effect: remember OwnerId of source cell; RemoveStoneAt(src); ForcePlaceStone(OwnerId, Target); clear guardian on src if any; CheckWinAt(Target)
- Guardian-protected source → fail (Validate + Execute)

## Steal (ItemId=3)

- Guardian → fail with no state change
