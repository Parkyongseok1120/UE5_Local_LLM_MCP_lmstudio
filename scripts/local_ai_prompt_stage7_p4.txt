## Implement ExecuteItem switch (GomokuItemLibrary.cpp)
Map ItemId→EGomokuItemType via a small GetItemData(ItemId) table:
1=SealStone cost1 Cell; 2=Pull; 3=Steal; 4=SkipTurn Player; 5=GuardianBarrier Cell.

CanUseItem must use Engine->IsItemUsableNow (not just PlayerHasItem).

ExecuteItem flow:
- IsItemUsableNow
- ValidateTarget by TargetType
- ConsumePlayerEnergy(EnergyCost)
- apply effect:
  - SealStone: SetCellBlocked(cell,true) if empty
  - SkipTurn: SetPlayerSkipNextTurn(targetPlayerId,true)  // TargetPlayerIndex+1
  - Steal: if !IsCellGuardianProtected then ChangeCellOwnership
  - Pull: minimal — RemoveStoneAt neighbor toward player or ForcePlace; if too hard, implement Steal+Seal+Skip+Guardian first and stub Pull returning false
  - GuardianBarrier: SetCellGuardianProtected(cell,true)
- RemoveItemFromInventory; SetUsedItemThisTurn
