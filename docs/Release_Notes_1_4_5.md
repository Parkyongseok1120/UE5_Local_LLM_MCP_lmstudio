# v1.4.5 Release

**v1.4.5는 이 프로젝트의 마지막 릴리즈입니다. 2026년 11월 11일부터 프로젝트를 동결하며 추가 개발·유지보수·업데이트를 종료합니다.** 이전의 11월 30일까지 지원 예정 안내를 대체합니다.

## 주요 변경

- 로드된 모델의 전체 컨텍스트에 대한 비율로 입력 목표·트리거·출력·안전 여유를 계산하는 percentage 예산을 추가했습니다. 기존 legacy 설정도 유지합니다.
- 프로젝트 규칙의 범위·수명·페이지 읽기와 설치 패키지의 공통 도구 계약을 보완했습니다.
- 보고서의 의미 정정과 코드 공백을 보존하며, 정확한 반복만 억제하도록 중복 출력 처리를 개선했습니다.
- 검토 판단의 소유자와 기각 범위를 구분하고, 부분 소스 읽기를 허용하면서 명시적인 전량 읽기 주장만 실행 기록과 대조합니다.
- 보고 전달·검토 보완·목표 달성 상태를 분리하고 실제 모델 A/B 결과를 기록했습니다.

## 설치·업데이트


- `Evidence-First-Integrated-v1.4.5.zip`과 함께 제공되는 `.sha256` 파일을 다운로드하고 ZIP 해시를 확인합니다.
- ZIP을 새 폴더에 압축 해제합니다. 설치 후에도 이 폴더가 도구 실행에 사용되므로 보관합니다.
- Windows 신규 설치는 `INSTALL.bat`, 기존 연결과 같은 소스 폴더의 갱신은 `UPDATE.bat`를 사용합니다. 다른 폴더로 옮긴 경우에는 기존 프로젝트·엔진·인덱스·권한을 확인하면서 설치기로 실행 경로를 갱신합니다.
- Ubuntu·Apple Silicon macOS는 `./install.sh`를 사용합니다. 세부 옵션은 `PORTABLE-INSTALL.md`를 확인합니다.
- Intel Mac의 LM Studio GUI는 지원하지 않습니다. Linux x64 VM의 llmster/LM Link 구성은 `--headless-lmlink` 경로를 사용하며 GUI 전용 컴팩터를 제외합니다.
- 업데이트 후 LM Studio를 완전히 종료하고 다시 실행해 새 플러그인과 MCP 프로세스를 불러옵니다.
- 개인 설정·프로젝트 및 엔진 소스·로컬 RAG 인덱스는 ZIP에 포함하지 않습니다. 새 아키텍처 패턴의 RAG 검색은 해당 자료를 포함해 인덱스를 정상 갱신한 뒤 사용할 수 있습니다.

## 검증 범위

보고 품질 패치의 자동 테스트 1,408개와 생성물 검사 4종이 통과했습니다. 최종 main CI와 배포 ZIP·SHA256은 GitHub 릴리즈에 기록합니다.

동일 원문·legacy 예산의 실제 모델 A/B 1쌍을 최종 보고까지 실행했습니다. A/B 모델 호출은 21/37회, 백엔드 prompt eval은 799.11646/1,334.90277초였습니다. B의 요청된 압축 4회는 입력 예산 내로 줄어들었습니다. 단일 쌍과 미확인 sampling/seed로 속도 향상이나 품질 비열화를 입증할 수 없습니다.

## 알려진 문제와 한계

- 모델의 근거보다 넓은 정상 보장과 일부 부정확한 소스 설명이 남아 있습니다. 부분 읽기 자체는 결함이 아닙니다.
- 내부 도구 참조 및 작업 메모 노출, 검토 누락 오탐, 읽기 예약과 입력 재처리 비용에 관한 후속 계획은 모두 완료된 수정으로 간주하지 않습니다.
- 보고 전달 성공은 감사 목표 충족이나 의미적 정확성의 증명이 아닙니다. 실제 모델 검토 보완이 새 본문을 전달하지 못한 사례도 기록했습니다.
- 동결은 알려진 한계의 해결이나 모든 환경의 설치·게임 실행을 보증하지 않습니다.

상세 구현과 실측 범위는 [보고 품질 수정 기록](Harness_Report_Quality_Implementation_20261111.md)을 참고하세요.
