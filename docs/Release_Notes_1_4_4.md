# v1.4.4 Release

LM Studio용 하네스·컴팩터·도구 계약 v4와 아키텍처 판단의 근거 관리를 포함한 1.4.x 유지보수 배포입니다. 1.4.3 이후의 읽기 예약, 대화 복원, 내부 데이터 출력과 보고서 중복 표시를 보완했습니다.

## 주요 변경

- 주 읽기 도구의 최소 예약을 기준으로 읽기 여유를 보호하고, 이미 관찰한 파일 크기·줄 수로 결과 크기를 추정합니다. 공급자가 반환한 최소 응답 크기를 다음 예약에 반영하며, 예산이 부족한 호출은 다음 라운드로 미뤘다고 표시합니다.
- 선택 안내문과 런타임 데이터의 통합을 실제 입력 재작성 시점에 맞춥니다. 복원된 큰 입력은 첫 라운드 전에 정리하고, 단순 설명에는 불필요한 안내문을 생략하며 system prefix 변경 원인을 기록합니다.
- 반환된 소스의 구조 단서와 최신 직접 관찰 버전을 구분합니다. 아키텍처 판단은 현재 모델 입력에 포함된 근거·패턴 참조에 연결하고, 소스 변경·취소·프로젝트 변경에 따라 무효화하거나 과거 판단으로 복원합니다.
- Unreal 설계 패턴 카드 16개와 공통 catalog를 추가했습니다. 모델 안내문과 RAG용 자료를 같은 원본에서 생성하며, 일반 패턴 지식을 프로젝트 소스나 엔진 API 검증으로 취급하지 않습니다.
- 내부 reference JSON·검토 기록 행·근거 제어 줄을 사용자 답변과 저장된 답변에서 걸러냅니다. 필터를 거친 본문을 실제 전달·완료 판정·대화 저장에 사용하고, 일반 설명과 실제 내부 데이터의 경계를 보완했습니다.
- 보고서 검토가 이미 전달한 본문을 작은 수정이나 중간 섹션 삽입과 함께 반복하면 중복 부분을 숨기고 새 내용을 전달합니다. 보고 범위 정정과 같은 식별자의 소유자 구분도 보완했습니다.
- 삭제 승인을 제안 당시 파일 버전에 연결하고, 실제 삭제가 완료된 경우에만 기존 빌드 변경 원장에 반영합니다. 시작 시 복구는 실행 중인 트랜잭션이나 사용 중인 대상 경로를 보류하며 저널을 유지합니다.
- 단건 수정과 묶음 수정의 `expectedOccurrences` 기본값을 공통 처리합니다. 읽기 응답의 metadata만으로 예산이 넘치면 최소 응답 크기를 안내합니다.
- 공개 문서의 로컬 경로를 환경 별칭으로 정리했습니다. 복구 회귀의 임시 폴더를 물리 경로로 고정해 Windows 단축 경로와 macOS 임시 폴더 별칭에서도 같은 계약을 검사합니다.

## 설치·업데이트

- `Evidence-First-Integrated-v1.4.4.zip`과 함께 제공되는 `.sha256` 파일을 다운로드하고 ZIP 해시를 확인합니다.
- ZIP을 새 폴더에 압축 해제합니다. 설치 후에도 이 폴더가 도구 실행에 사용되므로 보관합니다.
- Windows 신규 설치는 `INSTALL.bat`, 기존 연결과 같은 소스 폴더의 갱신은 `UPDATE.bat`를 사용합니다. 다른 폴더로 옮긴 경우에는 기존 프로젝트·엔진·인덱스·권한을 확인하면서 설치기로 실행 경로를 갱신합니다.
- Ubuntu·Apple Silicon macOS는 `./install.sh`를 사용합니다. 세부 옵션은 `PORTABLE-INSTALL.md`를 확인합니다.
- Intel Mac의 LM Studio GUI는 지원하지 않습니다. Linux x64 VM의 llmster/LM Link 구성은 `--headless-lmlink` 경로를 사용하며 GUI 전용 컴팩터를 제외합니다.
- 업데이트 후 LM Studio를 완전히 종료하고 다시 실행해 새 플러그인과 MCP 프로세스를 불러옵니다.
- 개인 설정·프로젝트 및 엔진 소스·로컬 RAG 인덱스는 ZIP에 포함하지 않습니다. 새 아키텍처 패턴의 RAG 검색은 해당 자료를 포함해 인덱스를 정상 갱신한 뒤 사용할 수 있습니다.

## 검증 범위

배포 기준은 최종 main 커밋의 GitHub CI 전체 통과입니다. Windows·Ubuntu·macOS의 MCP·컴팩터 회귀, Python·정적·인코딩·PowerShell 검사와 깨끗한 포터블 패키지 검사를 확인합니다. 최종 커밋·CI 실행·배포 파일 해시는 GitHub 릴리즈 본문에 기록합니다.

릴리즈 준비 중 임시 경로 별칭을 사용한 Node 20 재현에서 수정 전 복구 회귀 2개가 실패했고, 물리 경로로 고정한 뒤 4개 전체가 통과했습니다. 공개 문서 경로 위생 검사 4개도 통과했습니다. 이 결과와 CI의 자동 검사는 모든 환경의 실제 설치나 게임 실행을 인증하지 않습니다.

## 알려진 문제와 한계

- 구조·claim·소스 사실의 의미 매칭은 휴리스틱입니다. 형식 검사, 패턴 선택, 소스 개요와 모델의 자기 선언은 사실 검증·감사 완료·실제 변경 성공의 증명이 아닙니다.
- 아키텍처 판단의 결정적 회귀와 실제 모델의 의미 품질·재조회·지연 개선은 구분합니다. 같은 조건의 반복 실모델 비교를 완료하지 않았으므로 성능 개선 비율을 보장하지 않습니다.
- 기존 인덱스에 새 패턴 corpus가 없으면 미확인 상태로 처리합니다. 설치만으로 개인 RAG 인덱스의 내용이나 세대를 자동 갱신하지 않습니다.
- 이전 실행 기록과 설치 확인은 해당 시점의 관찰입니다. 현재 배포본의 모든 장비·엔진·프로젝트 조합에 대한 설치·실행 증명이 아닙니다.
- 1.4.x가 마지막 배포 계열이며, 최적화·안정화 지원은 2026년 11월 30일까지 예정되어 있습니다. 1.5 배포 계획은 없습니다.
