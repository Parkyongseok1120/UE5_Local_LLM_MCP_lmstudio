# v1.4.2 Release

LM Studio에서 로컬 모델이 Unreal·Unity 프로젝트를 탐색하고 코드를 읽고 수정할 수 있도록 연결하는 통합 배포입니다. 1.4.1 이후의 반복 읽기와 근거 상태 보존, 인용·엔진 근거 대조, 빌드 전 정적 검사와 범위 편집, CI·배포 구성을 개선했습니다.

## 주요 변경

- 같은 파일·SHA·범위를 이미 읽었는지 기록하고, 반복 본문을 원문 복구 위치와 관찰 사실로 대체합니다. 새 SHA와 새 범위, 처음 집중해서 읽는 범위, 압축 후 필요한 근거 복구는 허용합니다. 실제 변경 후 과거 SHA로 돌아오는 경우도 최신 관찰로 갱신합니다.
- 압축으로 원문이 사라져도 전달 범위와 검토 주장 이력을 구분해 보존합니다. 모델의 자기 선언이나 형식 검사 성공을 사실 검증·파일 감사 완료로 승격하지 않습니다. 필요한 근거를 읽는 작업과 실패한 읽기를 단순 정체로 처리해 조기 종료하지 않도록 보완했습니다.
- 작은 프로젝트 소스의 줄 번호 포함 전체 읽기, 확대된 기본 읽기 예산, 보관 본문의 줄 범위·심볼 복구를 지원합니다. 원문을 줄일 때 인용한 줄과 소스 개요를 유지하고, 본문을 대체하는 복구 참조가 해당 SHA·범위를 실제로 포함하는지 확인합니다. 소스 개요는 탐색 힌트이며 원문 근거와 구분합니다.
- 보고서와 근거 패킷의 인용을 반환된 원문과 대조하고, 엔진 동작 주장·새로 사용한 엔진 API에 필요한 근거가 부족한 경우를 알립니다. 감사 요청에서는 수정·삭제·프로젝트 전환 도구 노출을 줄이고 다른 검증·MCP 도구는 유지합니다.
- `Runtime read-result budget facts` 같은 내부 budget·ledger·projection 안내가 일반 답변으로 재출력되는 경로를 보완했습니다. 안내는 모델 입력에 유지하며 사용자 인용·설명 요청, 코드 블록, 실제 답변과 원래 도구 응답을 보존합니다.
- 변경한 Unreal 소스에 대한 빌드 전 정적 검사와 실제 실패 빌드에서 재구성한 회귀 코퍼스를 추가했습니다. 확정적으로 분류한 오류는 UBT 실행 전에 알려 주며, 근거가 충분하지 않은 검사는 경고 또는 미확인으로 남깁니다.
- 줄 범위와 `rangeSha256`에 기반한 편집을 지원합니다. 원문 범위가 달라지면 충돌을 반환하며, 빌드 성공 뒤에는 관련 Automation 테스트를 제안합니다. 테스트 제안을 실제 테스트 실행·성공으로 취급하지 않습니다.
- LM Studio 실행 로그의 라운드·도구 호출·파일·줄 범위·반복 읽기·프롬프트 처리·생성 시간 등을 분석하는 읽기 전용 스크립트를 추가했습니다.
- 최근 분석기·코퍼스 회귀를 세 운영체제의 CI에 편입하고 Windows의 중복 suite 실행을 정리했습니다. 잠금 경쟁 검사를 결정적인 조건으로 구성하고, 공개 경로·문서 링크·포터블 패키지의 필수 소스 누락을 수정했습니다.

## 설치·업데이트

- 첨부된 `Evidence-First-Integrated-v1.4.2.zip`을 새 폴더에 압축 해제합니다.
- Windows 신규 설치는 `INSTALL.bat`, 기존 설치 업데이트는 `UPDATE.bat`를 사용합니다. 기존 프로젝트·엔진·인덱스·권한 설정을 확인하며 연결된 MCP와 대화 압축기를 갱신합니다.
- Ubuntu·Apple Silicon macOS는 `./install.sh`를 사용합니다. 자세한 옵션은 배포본의 `PORTABLE-INSTALL.md`를 확인합니다.
- Intel Mac의 LM Studio GUI는 지원하지 않습니다. Linux x64 VM의 llmster/LM Link 구성은 `--headless-lmlink` 경로를 사용하며 GUI 전용 대화 압축기는 제외됩니다.
- 업데이트 후 LM Studio를 완전히 종료하고 다시 실행해 새 플러그인과 MCP를 불러옵니다.
- 프로젝트·엔진 소스, 개인 경로·설정과 로컬 RAG 인덱스는 배포 ZIP에 포함하지 않습니다.
- 다운로드한 ZIP의 SHA-256을 함께 첨부된 `.sha256` 파일과 비교할 수 있습니다.

## 검증 범위와 한계

배포 기준은 최종 main 커밋의 GitHub CI 전체 통과입니다. Windows·Ubuntu·macOS의 Direct MCP·Unity MCP·대화 압축기, Python 회귀·반복 검사, 정적·인코딩·PowerShell 검사, 휴대용 설치와 패키지 검사를 포함합니다. 배포 파일은 깨끗한 소스에서 생성하고 인벤토리의 각 SHA-256과 ZIP 내용을 확인합니다. 최종 소스 커밋·CI·패키지 해시는 GitHub 릴리스 본문의 배포 검증 기록에 남깁니다.

릴리스 준비 전 로컬 검사에서는 Python CI 1,028개, Compactor 963개, Unreal MCP 358개가 통과했습니다. 반복 읽기·정상 근거 복구·조기 종료·일반 채팅의 내부 안내 노출은 합성 회귀로 검사했습니다. **이번 수정 후 동일 조건의 장기 실모델 감사 비교는 미실행**이며, 일정한 시간 단축이나 감사 정확도 향상을 보증하지 않습니다.

빌드 실패 코퍼스는 관측된 실패 빌드 51건을 39개 최소 재현 사례로 정리한 것입니다. 합성 엔진 선언으로 재현하는 검사에서는 48/51건을 검출하며 33/51건은 오류 등급입니다. 이 수치는 전체 Unreal 오류에 대한 검출률이나 모델의 자동 수정 성공률이 아니며 실제 UBT·UHT·게임 실행을 대신하지 않습니다.

자세한 수정·한계는 저장소의 [컴팩터 검토 후 수정 기록](https://github.com/Parkyongseok1120/UE5_Local_LLM_MCP_lmstudio/blob/main/docs/Compactor_Review_Fixes_And_Update_20261025.md)에 있습니다. 자동 검사는 모든 기기·엔진·프로젝트의 실제 설치·컴파일·게임플레이를 인증하지 않습니다. 기존 1.4.x 유지보수 범위와 지원 종료 안내는 그대로 적용됩니다.
