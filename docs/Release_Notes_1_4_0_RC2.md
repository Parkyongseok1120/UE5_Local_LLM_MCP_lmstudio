# v1.4.0-RC2 변경 사항

이번 시험 배포는 RC1 이후 LM Studio의 도구 실행 상태, 장기 대화의 근거 관리, 언리얼·유니티 작업 지침과 MCP 책임 경계를 보강합니다. 모델을 추가로 호출하거나 별도 에이전트를 실행하지 않고 기존 도구와 컨텍스트 관리 경로에서 처리합니다.

## 주요 변경 사항

### 대화 압축기와 도구 실행

- 공유 읽기 예산에서 언리얼 파일 읽기의 생략된 기본 창을 4 KiB 이하로 예약해 여러 파일을 함께 조회할 때 한 요청이 예산을 독점하는 문제를 완화합니다. 명시한 큰 읽기 창과 최종 입력 토큰 검사는 유지합니다.
- 컨텍스트 여유가 있을 때 아직 모델 입력에 전달하지 않은 도구 원문을 크기만으로 미리 축소하지 않습니다. 입력 한도에 가까워지면 기존 압축·발췌·재측정을 적용하고 생략 범위를 기록합니다.
- 도구 인수 생성이 출력 한도에 도달하거나 JSON 해석에 실패하면 해당 요청을 미실행 상태로 종료하고, 이미 정상 반환된 결과와 미완료 범위를 부분 보고합니다.
- 언리얼의 byte·line 범위 읽기 결과를 부분 보고에 포함합니다. 다른 호출이 미완료여도 개별적으로 확인된 결과는 보존하며, 고립·중복·실패 응답을 정상 근거로 취급하지 않습니다.
- 도구 거부·취소·라운드 종료에서 대기 상태를 정리하고, 종료 전의 미완성 생성 관측을 오류 분류에 유지합니다. LM Studio의 저장된 승인 설정과 기본 승인 표시 경로를 연결합니다.
- 실제 파일 수정 전후의 해시와 제한된 변경 근거를 유지하고, 이후 파일 상태가 달라지면 이전 근거를 무효화합니다. 수정 결과와 전체 작업 완료를 구분합니다.

### 설계 참고 문서와 Auto

- 단일 진실 공급원(SSOT), SOLID, 디버깅·API 계약, 가독성, 엔진 소유권·생명주기, 멀티플레이 계약을 다루는 공통 및 엔진별 참고 문서를 제공합니다.
- Auto는 최신 사용자 요청과 확인된 도구 관찰을 기존 문서 선택기에 전달합니다. 한국어 조사 요청과 명시된 두 주제를 인식하고, 현재 진단에 필요한 보조 지침을 우선합니다.
- 참고 문서는 기존 섹션 수와 토큰 예산 안에서 선택적으로 주입합니다. 기본 Off 설정을 유지하며, 필수 정적 검사나 자동 코드 변경을 추가하지 않습니다.

### 언리얼·유니티 및 RAG

- 언리얼의 설치된 엔진 버전과 로컬 헤더를 확인하는 명시적 `engine_local` 심볼 조회를 보강합니다. 선언의 위치·범위·해시를 제공하며, 제한된 탐색에서 검색 결과가 없다는 이유로 API 부재를 단정하지 않습니다.
- 언리얼 파일 수정, 유니티 Bridge, RAG 갱신에서 실행·적용·기록 저장·결과 전달·후속 정리의 책임을 구분합니다. 적용 이후의 전달·정리 실패가 실제 적용 결과를 덮어쓰지 않도록 보강합니다.
- 취소 시점과 프로세스 수명을 구분하고, 결과를 확인할 수 없는 실행은 불명 상태로 처리합니다. 종료된 요청의 늦은 결과가 새 상태를 덮어쓰는 경로를 방어합니다.
- 대화 메모의 작업 범위, 도구 요청·결과 연결, 읽기 실패와 제한된 검색의 의미를 정리합니다. 파일 복구는 기록된 물리 경로와 소유권을 확인하고 외부 변경을 보호합니다.

### 근거 검토 서버와 설치

- `evidence_first_validate`는 주장 하나 또는 작은 묶음의 형식·기록 일관성을 검사하도록 계약과 프리셋을 정리합니다. 형식 검사 성공은 실제 사실성이나 전체 작업 완료를 인증하지 않습니다.
- 지원되지 않는 스키마 정규식을 제거하고 서버의 공백·타입 검사를 유지합니다.
- 설치 게시가 성공한 뒤 임시 자료 정리에 실패하면 경고로 처리하며, 게시 자체가 실패한 경우의 기존 설치 복구는 유지합니다.
- 공개 문서의 개인 PC 경로를 상대 경로와 명시적 자리표시자로 정리하고, Windows·macOS 복구 테스트의 물리 경로 기록과 CI 검사 목록을 보정합니다.

## 검증 범위

배포는 최종 Develop 커밋의 GitHub CI 전체 통과를 기준으로 진행합니다. Windows·Ubuntu·macOS에서 Direct MCP, Unity MCP, 컨텍스트 컴팩터와 휴대용 설치·패키징 경로를 검사하며, Windows에서는 정적 검사와 반복 실행 검사를 추가로 수행합니다.

압축기의 이전 로컬 전체 검사는 506개, 근거 검증·설치·패키징 관련 검사는 143개가 통과했습니다. 이는 기능 회귀 검사 결과이며 모델의 추론 정확도·작업 성공률·속도 향상을 측정한 수치는 아닙니다. RC2 설치 후 실제 LM Studio 모델과 Unity 에디터에서의 최종 동작 확인은 별도로 필요합니다.

## 설치 및 업데이트

- 첨부된 통합 ZIP을 새 디렉터리에 풀고 해당 플랫폼의 설치·업데이트 실행기를 사용합니다.
- 압축기, 근거 검토 서버와 프리셋을 함께 갱신한 뒤 LM Studio에서 새 실행으로 확인합니다.
- Unity Bridge가 다른 소스 트리에 연결되어 있다는 업데이트 오류가 발생하면 통합 `install.py`의 Unity 설치 경로로 연결을 이전합니다.
- 엔진 설치 경로, 게임 프로젝트 및 RAG 인덱스는 로컬 설정과 탐지 결과를 사용합니다. 배포 ZIP에 개인 경로나 로컬 인덱스를 포함하지 않습니다.
