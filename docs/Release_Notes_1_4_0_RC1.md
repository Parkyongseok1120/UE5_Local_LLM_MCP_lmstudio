# v1.4.0-RC1 변경 사항

이번 시험 배포는 beta4 이후 LM Studio 대화 압축기의 중단·재진입, 근거 수명, 보고 복구를 보강합니다.

## 주요 변경 사항

- 화면에 실제로 기록된 메시지 블록을 기준으로 다음 턴의 원본 대화 경계를 만들고, 여러 도구 요청이 나뉘어 저장돼도 같은 요청 묶음으로 검증합니다.
- 반환된 도구 결과와 완료된 계획만 종료 작업 창에 보존합니다. 중단된 설명·reasoning은 승격하지 않으며, 다음 호출에서 입력을 다시 정확히 측정합니다.
- 도구 세션의 종료를 보장하고, 복원 실패 사유를 범위·원본 prefix·참조·무결성으로 구분합니다.
- 읽기 결과가 성공과 오류로 섞인 경우에도 성공한 결과를 다음 조사와 보고에 사용할 수 있도록 합니다. 일반 자동 복구 보고에는 제한형 조사의 70초 제한을 적용하지 않습니다.
- 대체 보고에 반환된 파일 범위와 짧은 본문 발췌를 포함하고, 시간 초과와 출력 한도 도달을 구분합니다.
- 설치 상태 검사에서 LM Studio CLI가 생성한 정상 플러그인 entry 형식을 인정합니다.

## 검증 범위

중단 후 다음 턴 복원과 혼합 도구 결과의 처리는 자동 회귀 테스트로 확인했습니다.
실제 로드된 LM Studio 모델에 기존 두 파일의 반환 결과를 재생했을 때 보고 본문은 생성됐지만
8192 출력 토큰 한도에 도달하여 완결되지는 않았습니다. 설치본의 소스·빌드 지문은 작업본과
일치했습니다. GUI에서 중단된 기존 대화를 다시 실행한 검증은 포함하지 않습니다.

자세한 원인, 책임 경계와 검증 기록은
[컴팩터 연속성 조사](https://github.com/Parkyongseok1120/UE5_Local_LLM_MCP_lmstudio/blob/v1.4.0-RC1/docs/investigations/compactor-continuity-2026-09-25/README.md)에 정리했습니다.
