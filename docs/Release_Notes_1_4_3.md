# v1.4.3 Release

LM Studio용 하네스·컴팩터·도구 계약을 v3로 정리한 1.4.x 유지보수 배포입니다. 1.4.2 이후의 컨텍스트 연속성, 원문 보존, 보고서 이어쓰기와 도구 결과 경계를 보완했습니다.

## 주요 변경

- 사용자 목표를 감사·수정·빌드·설명으로 구분해 실행 수명으로 유지합니다. 실제 변경 결과로만 적용 완료를 인정하고, 변경을 적용하지 못한 종료에는 미적용 고지를 붙입니다.
- 도구 라운드의 계속·집중·종료 판정을 한 곳으로 모았습니다. 수정 목표가 컨텍스트 압력을 받으면 변경 도구를 포함한 집중 라운드를 먼저 시도합니다.
- 도구 효과·결과 종류·역할을 manifest에서 생성해 profile, guard, 예약과 결과 처리에 공유합니다. 파일 본문·검색 결과·보관 페이지와 고정 비용 도구를 구분합니다.
- 알려진 결과 크기의 읽기 예약과 다음 최소 읽기 여유를 개선했습니다. 공급자의 재시도 최소 예산을 보존하며 SDK 거부와 실제 하네스 예산 거부를 구분합니다.
- 반환 소스 사실을 ReadLedger로 통합했습니다. 검색에서 반환한 줄과 파일 coverage, 현재 입력의 가시성, 모델의 검토 주장을 분리하고 execution/conversation 범위를 표시합니다.
- 변경 대상과 미해결 claim 범위를 우선 보존합니다. 직전 감사의 변경 대상은 다음 checkpoint 후에도 유지하고, 압축·복구가 같은 핀 허용량을 사용합니다. 선택 안내문은 남은 공간에만 넣습니다.
- 보고서 이어쓰기, SDK 결과 전달과 취소·복구의 경계를 보완했습니다. 메모·발췌·복구 권한과 실제 반환 근거의 수명을 구분합니다.
- 첫 집중 읽기·필요한 복원·반복 복원, 목표 상태, 변경 집중 라운드와 system prefix 변경 계측을 추가했습니다. 분석기는 구버전의 모호한 복원 통계를 별도로 표시합니다.
- 작업트리 탐색, repeat 응답의 호환 문구와 공개 문서 경로를 정리하고, 새 런타임·문서를 포터블 패키지의 명시적 목록에 추가했습니다.

## 설치·업데이트

- `Evidence-First-Integrated-v1.4.3.zip`과 함께 제공되는 `.sha256` 파일을 다운로드하고 ZIP 해시를 확인합니다.
- ZIP을 새 폴더에 압축 해제합니다. 설치 후에도 이 폴더가 도구 실행에 사용되므로 보관합니다.
- Windows 신규 설치는 `INSTALL.bat`, 기존 연결과 같은 소스 폴더의 갱신은 `UPDATE.bat`를 사용합니다. 다른 폴더로 옮긴 경우에는 기존 프로젝트·엔진·인덱스·권한을 확인하면서 설치기로 실행 경로를 갱신합니다.
- Ubuntu·Apple Silicon macOS는 `./install.sh`를 사용합니다. 세부 옵션은 `PORTABLE-INSTALL.md`를 확인합니다.
- Intel Mac의 LM Studio GUI는 지원하지 않습니다. Linux x64 VM의 llmster/LM Link 구성은 `--headless-lmlink` 경로를 사용하며 GUI 전용 컴팩터를 제외합니다.
- 업데이트 후 LM Studio를 완전히 종료하고 다시 실행해 새 플러그인과 MCP 프로세스를 불러옵니다.
- 개인 설정·프로젝트 및 엔진 소스·로컬 RAG 인덱스는 ZIP에 포함하지 않습니다.

## 검증 범위

배포 기준은 최종 main 커밋의 GitHub CI 전체 통과입니다. Windows·Ubuntu·macOS의 MCP·컴팩터 회귀, Python·정적·인코딩·PowerShell 검사와 깨끗한 포터블 패키지 검사를 확인합니다. 최종 커밋·CI 실행·배포 파일 해시는 GitHub 릴리즈 본문에 기록합니다.

v3 구현 커밋의 로컬 회귀는 컴팩터 1,131개, Unreal agent 365개, Unity 132개, Python 1,487개가 통과했고 실패는 0건이었습니다. 플랫폼별 제외는 agent 2건·Unity 5건·Python 41건입니다. 설치된 실행 번들의 빌드 식별자 일치, MCP 초기화 및 evidence-first 계약 호환도 확인했습니다. 이 수치는 모든 환경의 실제 설치나 게임 실행을 인증하지 않습니다.

## 알려진 문제와 한계

- 오래된 추론을 먼저 정리하면 입력이 들어가는 경우에도 원문을 먼저 projection하는 경로가 있습니다. 합성 대조 실험에서 불필요한 원문 유실을 확인했으며 이번 배포에서는 아직 수정하지 않았습니다.
- 기각 문맥과 잠정 조사 계획을 found로 분류해 불필요한 report_review 라운드가 추가될 수 있습니다. 실제 대화 재생에서 확인했으며 이번 배포에서는 아직 수정하지 않았습니다.
- claim과 소스 사실의 의미 매칭은 휴리스틱입니다. 형식 검사, 소스 개요와 모델의 자기 선언은 사실 검증·감사 완료·실제 변경 성공의 증명이 아닙니다.
- 동일 조건의 감사→수정 2턴을 3회 반복하는 실모델 W7은 미실행입니다. 재조회 감소율, prefill 단축률이나 작업 완료율의 개선을 보장하지 않습니다.
- 1.4.x 유지보수 및 지원 종료 안내는 유지합니다. 1.5 배포 계획은 없습니다.

구현 계약과 자동 회귀의 상세 내용은 [v3 구현 기록](Harness_Compactor_Tool_Contract_v3_20261027.md)에 있습니다.
