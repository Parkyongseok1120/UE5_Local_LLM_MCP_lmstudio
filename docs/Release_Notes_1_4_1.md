# v1.4.1 Release

LM Studio에서 로컬 모델이 Unreal·Unity 프로젝트를 탐색하고 코드를 읽고 수정할 수 있도록 연결하는 통합 배포입니다. 1.4.0 이후의 읽기·편집 계약, 엔진 근거 전달, 대화 압축기의 프롬프트 재사용과 평가 기록을 개선했습니다.

## 주요 변경

- 대화 압축기의 실행 중 참고 정보를 이미 전달한 위치에 유지하고 새 관찰만 덧붙여, 같은 턴의 반복 도구 호출에서 프롬프트 앞부분을 재사용하기 쉽게 했습니다.
- 이전 턴에서 확인한 엔진 정보를 현재 지침 선택에 연결합니다. 프로젝트 전환, 엔진 버전·출처 충돌, 더 최신 관찰이 있으면 기존 정보를 그대로 적용하지 않습니다. 입력 예산이 부족할 때는 선택한 최소 지침을 우선 유지합니다.
- Unreal 프로젝트 소스의 암묵적 전체 읽기를 크기와 관계없이 제한하고 검색·심볼·범위 읽기를 안내합니다. 소스가 아닌 작은 설정 파일과 명시적인 byte window는 별도 계약을 따릅니다.
- 전체 읽기를 거부했을 때 파일 첫 부분을 읽는 제안 대신, 해당 파일과 프로젝트로 범위를 한정한 검색 템플릿을 제공합니다. 호출자가 검색어를 채워야 하며 빈 인자의 실행 가능한 호출로 바꾸지 않습니다.
- 읽기 범위가 완료됐을 때 불필요한 다음 페이지 안내를 생략합니다. 심볼의 선언·멤버 읽기와 엔진 근거 조회, 편집 실패 후 후보 범위·해시 안내를 보강했습니다.
- 여러 영역을 한 번에 편집하는 입력, hash·snapshot·receipt에 기반한 연속 편집과 충돌 거부를 보강했습니다. 변경 도구의 입력·결과 계약을 관련 회귀 검사에 포함합니다.
- Unreal 버전별 계약과 정적 검토 도구, Unity 도구·검증 계약을 보강했습니다. 구조 검사 성공과 실제 소스 사실 확인, 보고서 전달과 결론의 정확도를 구별합니다.
- 정확도 평가의 사례별 파일 접근을 격리하고 정상 동작 전제를 보완했습니다. 엔진 빌드·소스 해시를 확인하며 전체 표시 답변과 도구 결과·모델 설정을 기록합니다. 판정·원인 설명·인용 정확도를 별도로 검토하고 과거 오판 철회는 실제 후속 턴으로 확인합니다.
- 설치기·배포 패키지 검사의 오래된 버전 기대값과 공개 문서의 개인 로컬 경로를 수정했습니다. Unity 설치·업데이트의 `npm ci`에 필요한 잠금 파일을 배포본에 포함하고, 설치 안내는 현재 제품 버전의 릴리스 문서를 가리킵니다.

## 설치·업데이트

- 첨부된 `Evidence-First-Integrated-v1.4.1.zip`을 새 폴더에 압축 해제합니다.
- Windows 신규 설치는 `INSTALL.bat`, 기존 설치 업데이트는 `UPDATE.bat`를 사용합니다. 기존 프로젝트·엔진·인덱스·권한 설정을 확인하며 연결된 MCP와 대화 압축기를 갱신합니다.
- Ubuntu·Apple Silicon macOS는 `./install.sh`를 사용합니다. 자세한 옵션은 배포본의 `PORTABLE-INSTALL.md`를 확인합니다.
- Intel Mac의 LM Studio GUI는 지원하지 않습니다. Linux x64 VM의 llmster/LM Link 구성은 `--headless-lmlink` 경로를 사용하며 GUI 전용 대화 압축기는 제외됩니다.
- 업데이트 후 LM Studio를 완전히 종료하고 다시 실행해 새 플러그인과 MCP를 불러옵니다.
- 프로젝트·엔진 소스, 개인 경로·설정과 로컬 RAG 인덱스는 배포 ZIP에 포함하지 않습니다.
- 다운로드한 ZIP의 SHA-256을 함께 첨부된 `.sha256` 파일과 비교할 수 있습니다.

## 검증 범위

배포 기준은 최종 main 커밋의 GitHub CI 전체 통과입니다. Windows·Ubuntu·macOS의 Direct MCP·Unity MCP·대화 압축기, Python 회귀·반복 검사, 정적·인코딩·PowerShell 검사, 휴대용 설치와 패키지 검사를 포함합니다. 배포 파일은 깨끗한 소스에서 생성하고 인벤토리의 각 SHA-256과 ZIP 내용을 확인합니다. 최종 CI와 패키지 검증 기록은 GitHub 릴리스 본문에 첨부합니다.

로컬 검사에서는 Compactor 855건, Unreal MCP 337건과 설치·버전 관련 24건을 통과했습니다. 실제 LM Studio 모델의 일부 사례에서 엔진 지침 전달, 정상 Client RPC 설명, 결함의 차단 원인과 과거 오판 철회를 확인했습니다. 일부 사례에는 원인 설명·인용 오류가 남아 있으며, 전체 정확도 향상과 일정한 속도 개선률을 보증하지 않습니다. 실제 게임 감사의 처리 시간 감소 관측은 동일 조건의 전체 비교 시험과 구별합니다.

자세한 평가 조건과 한계는 저장소의 [평가·읽기 안내 보정 기록](https://github.com/Parkyongseok1120/UE5_Local_LLM_MCP_lmstudio/blob/main/docs/Harness_Eval_Read_Repair_20261019.md)에 있습니다. 자동 검사는 모든 기기·엔진·프로젝트의 실제 설치·컴파일·게임플레이를 인증하지 않습니다.
