# v1.4.0 Release

LM Studio에서 로컬 모델이 Unreal·Unity 프로젝트의 코드를 탐색하고, 근거를 읽고, 명시적으로 허용된 수정·빌드·검증 도구를 사용할 수 있도록 구성하는 통합 배포입니다. 이번 정식 버전은 beta·RC 계열의 설치·실행 경로를 포함하고, 긴 대화의 문맥 보존과 출력 중단 후 이어쓰기를 개선합니다.

## 주요 변경

- Unreal Direct MCP의 프로젝트 탐색, 파일·심볼 읽기, Git 조회, 제한된 코드 수정, 빌드·진단 도구를 제공합니다.
- Unity 전용 MCP와 Editor Bridge를 제공하고 프로젝트 종류에 맞는 도구를 노출합니다. 실제 Editor 검증 범위는 Unity 지원 문서에 구분합니다.
- 출력 한도에 도달한 보고서는 기존 본문을 입력에 유지한 채 최대 한 번 자동으로 이어 씁니다. 추가 본문은 같은 답변 블록에 붙이며, 일반 모드의 기존 90초 재작성 제한은 적용하지 않습니다.
- 취소·출력 중단 후에도 이미 표시한 본문과 채택된 연속성 노트를 보존합니다. 최근 대화·이전 답변·아직 소비되지 않은 도구 결과의 압축 보존과 저장 창 복원을 보강합니다.
- 로드된 컨텍스트 크기에 맞춰 압축 임계값을 조정하고, 토큰 측정 결과를 실행 내에서 재사용합니다. 별도 의미 요약 호출은 기본적으로 꺼져 있습니다.
- 읽기 결과의 바이트·추정 토큰 예산을 구분하고 중복 예약을 줄입니다. MCP 응답과 도구 설명을 간결하게 만들고, 폴더 목록 페이지 조회와 로그 원본 범위 조정을 추가합니다.
- 파일 검색은 병렬 읽기·취소·검색 기한을 지원합니다. RAG 읽기 요청은 제한된 병렬 처리를 사용하고, 변경 작업은 진행 중인 읽기가 끝난 뒤 실행합니다.
- 설치·업데이트의 설정 보존과 실패 복구, 실행 빌드 식별, Windows·Ubuntu·macOS CI 검사를 보강합니다.
- 배포에 필요한 검색·RAG 병렬 처리 모듈을 포함합니다. 과거 실행 로그·평가 산출물·임시 스크린샷은 현재 소스 트리에서 제거합니다.

## 설치·업데이트

- 첨부된 `Evidence-First-Integrated-v1.4.0.zip`을 새 폴더에 압축 해제합니다.
- Windows 신규 설치는 `INSTALL.bat`, 기존 설치 업데이트는 `UPDATE.bat`를 사용합니다.
- Ubuntu·Apple Silicon macOS는 `./install.sh`를 사용합니다. 자세한 옵션은 배포본의 `PORTABLE-INSTALL.md`를 확인합니다.
- Intel Mac의 LM Studio GUI는 지원하지 않습니다. Linux x64 VM의 llmster/LM Link 구성은 `--headless-lmlink` 경로를 사용하며 GUI 전용 컴팩터는 제외됩니다.
- 업데이트 후 LM Studio를 완전히 종료하고 다시 실행해 새 플러그인 코드를 불러옵니다.
- 프로젝트·엔진 경로와 로컬 RAG 인덱스는 배포 ZIP에 포함하지 않습니다.
- 다운로드한 ZIP의 SHA-256을 함께 첨부된 `.sha256` 파일과 비교할 수 있습니다.

## 검증 범위

배포 기준은 최종 main 커밋의 GitHub CI 전체 통과입니다. Direct MCP·Unity MCP·컨텍스트 컴팩터, Python 회귀·반복 검사, 정적·인코딩·PowerShell 검사, 휴대용 설치와 패키지 검사를 포함합니다. 패키지는 깨끗한 소스에서 생성하고 인벤토리 파일의 SHA-256을 확인합니다.

컴팩터의 실제 모델 검사에서는 출력 상한 뒤 자동 이어쓰기가 정상 종료되고 같은 답변 블록에 본문이 추가되는 것을 확인했습니다. 자동 검사는 모든 기기·엔진·프로젝트 조합의 실제 설치나 게임플레이를 인증하지 않으며, 모델의 UE 분석 정확도나 속도 개선률을 보증하지 않습니다.

실행 로그와 평가 산출물의 이전 내용은 Git 기록에서 확인할 수 있습니다. 테스트 코드와 테스트용 fixture는 유지합니다.
