# 반복 플레이 흐름

## 핵심 재미 검증 목표

이 프로토타입에서 검증할 가설을 한 문장으로 적어야 합니다.

## 30초 반복 플레이 구성

관찰 -> 판단 -> 행동 -> 반응 -> 회복 -> 다시 시도

## 필수 구현 기능

입력 1~3개, 바로 보이는 반응, 성공·실패 조건, 반복 가능한 테스트 장면을 적습니다.

## 선택 개선 기능

조작감을 높일 반응과 작은 난이도 변화를 적습니다.

## 프로토타입 제외 기능

성장·저장·상점·장비·큰 맵·멀티플레이·복잡한 UI 중 이번에 제외할 것을 적습니다.

## 최소 테스트 장면 구성

작은 맵, 플레이어 하나, 대상 1~2개, 반응 하나부터 확인해야 합니다.
