# 진행·결과 판정·상태 변경 구분

진행 담당자는 타이머·취소·재시도·중간 상태를 관리합니다. 상태 담당자는 최종 값을 보관합니다. 결과 판정은 필요한 정보가 어디에 있는지에 따라 수행자·대상·공유 규칙·별도 기능이 맡을 수 있습니다.

능력치·저항·환경·확률·난이도를 조합해야 한다면 필요한 자료와 호출 방향을 설명해야 합니다. 상태를 보관한다는 이유만으로 성공·실패 판단도 무조건 같은 객체에 둔다고 단정하지 않습니다.

최종 변경은 상태 담당자를 통해 적용합니다. 진행 완료 알림과 상태 변경 알림도 각각 어떤 사실을 알리는지 구분합니다.
