# 참고작의 핵심 플레이 경험 적용 기준

참고 게임은 무엇을 복사할지 고르는 목록이 아닙니다. 시점과 조작, 반복 행동, 행동 대상, 즉각적인 반응, 상태 변화, 압박과 선택을 나눠서 봅니다.

배틀로얄은 자원과 안전지대 때문에 교전·회피를 고르는 장면, 근접 액션은 공격을 읽고 회피·반격하는 장면, 덱빌딩은 비용 안에서 카드를 조합하는 한 차례부터 시험할 수 있습니다.

유명한 게임의 모든 주변 기능이나 고유 이름을 가져오지 말아야 합니다. 핵심 압박·행동·반응을 한 문장으로 적고 작은 장면으로 줄입니다. 성장·상점·장비·스토리·온라인 규모는 첫 재미 확인에 필요할 때만 포함합니다.
