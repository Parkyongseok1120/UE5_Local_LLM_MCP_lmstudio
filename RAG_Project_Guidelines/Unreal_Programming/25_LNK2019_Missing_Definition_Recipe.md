# 함수 구현 누락으로 인한 LNK2019 오류

`LNK2019`나 `CPP_DEFINITION_MISSING`이 나오면 정확한 클래스·함수와 기존 짝 `.cpp`부터 찾아야 합니다. 같은 모듈의 빠진 함수 구현을 모듈 추가로 고치려 하지 않습니다.

헤더의 반환형, 매개변수, 포인터·참조, `const`를 그대로 맞춥니다. 기본 인자와 `virtual`, `override`는 구현부에 반복하지 않습니다. 사용자가 뼈대만 요청한 게 아니라면 필요한 동작을 버리는 빈 함수로 끝내지 말아야 합니다.

RPC와 `BlueprintNativeEvent`는 UHT가 만드는 호출부와 직접 작성할 `_Implementation`을 구분합니다. `BlueprintImplementableEvent`, 인라인 구현, 순수 가상 선언 등도 확인 없이 중복 정의하지 않습니다.

헤더와 구현을 별도 호출로 작성하는 중간에 경고가 나오는 것 자체는 복구 사유가 아닙니다. 작업을 마칠 때 필요한 구현이 남아 있는지 확인해야 합니다. 다른 모듈의 함수라면 실제 정의·공개 매크로·의존성까지 확인합니다.

[선언·구현 일치 규칙](26_Header_Cpp_Signature_Alignment.md)과 실제 빌드 결과를 함께 사용해야 합니다.
