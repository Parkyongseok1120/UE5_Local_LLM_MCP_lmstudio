# 플랫포머·퍼즐·생존 프로토타입

## 플랫포머

이동·점프·착지·회피·수집을 반복합니다. 좌우 이동, 점프, 발판, 낙사 후 재시작, 수집물 하나부터 만들어야 합니다. 이동 물리와 점수·체크포인트·레벨 종료 규칙을 구분합니다. 점프 높이와 체공 시간 등 조작감을 확인하고 UI가 원본 점수를 관리하지 않게 합니다.

## 퍼즐

관찰·상호작용·규칙 반응·가설·해결을 반복합니다. 규칙 하나, 상호작용 대상, 성공·실패 표시, 초기화, 클리어 조건부터 만듭니다. 개별 객체의 상태와 전체 퍼즐 판정, 입력 요청, 결과 표현을 구분해야 합니다. 초기화할 상태가 여러 곳에 흩어지지 않게 합니다.

## 생존과 제작

탐색·채집·필요 자원 관리·제작·생존을 반복합니다. 자원 2~3종, 작은 인벤토리, 제작법 1~2개, 허기·체력·스태미나 중 하나, 위험 하나부터 만듭니다.

인벤토리는 소지품 원본, 자원 노드는 채집 가능 상태, 제작 기능은 비용과 결과 요청을 맡습니다. 자원 노드가 인벤토리 내부 배열을 직접 수정하지 않습니다. 생존 수치나 제작법을 처음부터 과하게 늘리지 말아야 합니다.
