# 슈팅 프로토타입

조준, 발사, 명중·빗나감, 피격 반응, 재장전·위치 이동이 바로 느껴지는지 확인해야 합니다.

처음에는 무기 하나, 체력 있는 대상, 카메라 조준, 즉시 판정 또는 투사체 중 하나, 피격 표시, 탄약·재장전만 구현합니다. 여러 무기·부착물·복잡한 탄도·네트워크는 별도 요청이 없다면 뒤로 둡니다.

무기는 발사 조건·탄약·대기시간·공격 요청을 맡습니다. 조준과 명중 판정, 대상 체력, 화면·소리 반응은 책임을 구분합니다. 무기가 대상 체력을 직접 고치지 않습니다.

작은 맵에서 조준부터 재장전까지 반복하고 맞았는지·빗나갔는지 즉시 알 수 있는지 확인합니다.
