# 검색 자료를 적용하는 범위

검색한 예시를 모든 프로젝트의 규칙처럼 쓰지 말아야 합니다. 자료가 일반 설계 원칙인지, 언리얼 구현 규칙인지, 장르별 기준인지, 특정 프로젝트의 사례인지 구분합니다.

일반 책임 분리와 상태 원본 규칙을 먼저 확인하고, 요청이 계획이면 계획 문서, 장르가 있으면 장르 문서, 언리얼이면 해당 구현 규칙을 함께 봅니다. 프로젝트 사례는 실제 대상과 맞을 때만 적용합니다.

예시에 방어막이나 특정 캐릭터가 있다고 모든 대상이 그 구조를 가져야 하는 것은 아닙니다. 다른 엔진이나 일반 도구 설계에 언리얼 함수 규칙을 그대로 적용하지 않습니다.

답변에는 어떤 종류의 근거를 어디에 적용했는지 적어야 합니다. 사용자 작성 규칙을 Epic 공식 문서로 소개하지 않습니다.
